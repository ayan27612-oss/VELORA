# VELORA

A minimal, intentional dating app prototype focused on real connections and simple pricing.

## Current build
- Responsive landing/discovery UI
- Mock profile discovery
- Intent filters
- Like/pass interactions
- Local-only profile form using browser storage
- Safety/product positioning baked into UX
- No Supabase, auth provider, payments, or external database yet

## Next
Auth → real profiles/photos → matching → chat → reporting/blocking → verification → subscriptions → admin.
